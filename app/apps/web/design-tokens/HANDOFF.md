# 职场色板交接（tokens only）

定稿：2026-10-09 锁定色板。本目录是色值与验收的交接，**不改牌桌像素**。`app/globals.css` 里现网毡面 / chip 变量仍负责绘制，下一轮实现再改接到 `--ws-*`。

## 锁定色值

| Token | Hex | 角色 |
|---|---|---|
| `--ws-desk` | `#2C3036` | 石墨哑光办公桌底 |
| `--ws-desk-sheen` | `#3E444C` | 同一块哑光板上的曲光，不是第二材质 |

| `--ws-score` | `#E85D04` | 得分橙 |

同色复用（P0 已过，不是新 hex）：座位暖边与浅卡底板 = `#E8E4D9`；浅底上的卡面深字 = `#2C3036`。

## 金属只三处

1. 暗标
2. 强制弹层金属框
3. 名牌 / 大数字描边

桌面、普通按钮、常驻面板、绩效条底板：零金属。玻璃轮廓不是金属。

## 行动黄独占

`#F5C518` 只用于：可点主行动 pill、选中黄描边、bid pill（0–8）。

揭晓 / bid pill **保持** `#F5C518`。揭晓后的出价数字仍是 bid pill，不是装饰黄。胜者绩效走得分橙 `#E85D04`。

## 验收（JOJO）：遮罩下选中黄描边必须关掉

强制浮层 / 强制弹层 / 对话框打开时，**压在它下面的选中黄描边（选中卡黄描边，以及被压住的 bid 黄描边 / outline）必须关掉**（`opacity: 0`，token `--ws-selected-stroke-under-overlay`）。

只把遮罩加黑、变暗、提到约 80% **不算通过**。遮罩可维持 72%，或辅助提到 75–80%，但不能代替关描边。关闭弹层后再恢复描边。

这条清的是底下的选中描边。揭晓层上的 bid pill 本身仍是行动黄 `#F5C518`。

## 可选磨砂玻璃

`#C5C9CE` @ 28% 只允许卡面底板和强制弹层轻轮廓。本 PR 不要求画上玻璃。禁止全屏铺玻璃。

## 禁止

绒布绿（废止 `#1A2E1C` / `#2A4A32`）、木纹、CRT、霓虹、全屏玻璃。不上赌场毡、不上灰蓝后台底。

## 本交接不做

不重绘毡面、卡、座位、浮层或 Liquid Glass。不接 Steamworks。不出商店素材 / P3。
